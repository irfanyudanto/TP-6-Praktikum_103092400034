# TP-6-Praktikum_103092400034

1. JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. Kegunaannya antara lain untuk merespons klik tombol, memvalidasi input formulir, menampilkan pesan, dan mengubah tampilan halaman web tanpa harus memuat ulang halaman.

2. jQuery adalah library JavaScript yang mempermudah penulisan kode JavaScript. jQuery digunakan untuk memanipulasi elemen HTML, mengubah CSS, menangani event seperti klik tombol, serta menyembunyikan dan menampilkan elemen dengan kode yang lebih sederhana.

3. JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript untuk mempermudah pengembangan web. JavaScript dapat digunakan secara langsung tanpa library tambahan, sedangkan jQuery perlu diimpor terlebih dahulu sebelum digunakan.
